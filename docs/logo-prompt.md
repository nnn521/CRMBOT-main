# CRMBOT Logo 生成提示词

> 粘贴以下提示词到豆包（doubao.com/chat）、Midjourney、DALL·E 等 AI 绘图中生成 Logo。

---

## 优化版（推荐使用）

### 方案一：对话方向盘

```
现代科技 Logo，AI 汽车销售助手品牌。

画面：一个极简的方向盘轮廓，上半部分断开并延伸成对话气泡的尾巴。方向盘中心是一个发光的蓝色小圆点（AI 核心），周围环绕 3 条细弧线表示数据流动。

配色：深蓝(#1A1A2E) + 电光蓝(#0EA5E9) + 白色背景
风格：扁平化矢量、线条干净、专业科技感
构图：图标居中偏左，右侧留白给文字，正方形画布
```

### 方案二：车头芯片

```
Logo 设计，主题：AI + 汽车销售。

画面：一个高度抽象的车头正面轮廓（仅用 3-4 条弧线概括），格栅区域替换为芯片电路纹理。车灯位置是两个小蓝色光点。整体像一枚徽章。

配色：深灰主色 + 蓝色光点点缀
风格：简洁、现代、有辨识度
构图：正方形，图标居中
```

### 方案三：C 形轨迹

```
科技感 Logo，品牌 CRMBOT。

画面：字母 "C" 由一条连续的渐变弧线构成，弧线起点细、终点粗。弧线内圈有 3 个亮点沿轨迹排列，像卫星环绕。整体像数据轨迹，又暗示车轮滚动。

配色：深蓝到青色渐变弧线 + 白底
风格：动感、科技、克制
构图：正方形
注意：不要画完整的车，只有弧线
```

### 方案四：蜂巢护盾

```
极简 Logo，象征 AI 助手的安全可靠。

画面：一个六边形（蜂巢）轮廓，内部被两条对角线分为 4 个区域。左上区域填充蓝色，其余留空。整体像盾牌 + AI 芯片的结合。

配色：深灰线条 + 蓝色填充一角 + 白底
风格：严谨、安全、极简
构图：正方形
```

## 文字修复版（纯图形，不加文字）

> ⚠️ AI 生图经常把英文字母拼错（CRMBOT → CRMBT / CRMBO / 乱码）。以下提示词只生成图形，后期自己用 Canva/Figma/PS 加文字。

### 图形 A：光轨之环

```
极简图形，无文字。

一个不闭合的圆环（约 300°），断口在右上方。圆环粗细渐变，从细到粗。断口处有一个发光蓝色小球。圆环下方有一个极小的三角箭头指向右方，象征前进和响应。

配色：深蓝圆环 + 蓝色发光球 + 白底
风格：科技、克制、高端
```

### 图形 B：三核交汇

```
抽象几何图形，无文字。

3 个大小相同的实心圆，呈三角排列。三圆交汇的中间重叠区域形成高亮白色三角。每个圆颜色不同：深蓝、中蓝、浅蓝。整体暗示多 Agent 协作。

配色：三种蓝色梯度 + 白底
风格：现代、专业
```

### 图形 C：脉冲波纹

```
极简图形，无文字。

画面中央一个实心蓝色小圆，外面扩散出 2 圈同心圆环（细线），最外圈不完整，右侧有缺口。象征 AI 正在监听、响应、脉冲。

配色：中央蓝色实心圆 + 灰色细圆环 + 白底
风格：安静、智能、克制
```

---

## 使用建议

1. 四个优化版都跑一遍，挑最顺眼的
2. 文字修复版生成的纯图形，用 Canva 加 "CRMBOT" 文字（字体推荐 Inter / SF Pro / 思源黑体）
3. 最终图标保存为 `frontend/public/logo.png`
