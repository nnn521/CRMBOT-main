# RAG v2 当前进度与剩余项

记录时间：2026-10-20。本文件区分“代码已实现并测试”和“已通过真实运行验证”，避免把模块完成当成整体验收。

## 已通过真实运行验证

- 独立 Docker 项目 `crmbot-rag-v2`：pgvector 0.8.0-pg16 健康，Ollama 在 11434 提供本地服务；未触碰其他项目。
- `bge-m3` 从官方分发下载、逐层 SHA-256 校验后导入；`/api/embed` 实测 1024 维、单位长度、支持批输入。
- 一次性隔离库完整链路：迁移 → 上传 → 持久构建任务 → 本地向量化 → 发布 → 检索 → 结构化综合回答 → 1 条稳定引用，`answer_status=answered`，用时约 5.9 秒（含建库与构建）。
- 真实数据库集成测试 70 项通过（storage 生命周期、API/worker、Wiki 原子写入与租约 fencing），容器已清理。
- 完整后端回归 633 通过 / 3 跳过；前端 typecheck 通过，契约测试 11 通过。

## 代码已实现、仅有假服务或单元测试

- TEI 重排适配器：默认关闭，协议与失败降级已测，但未部署真实重排模型，未测收益与 300ms 预算。
- Wiki 编译任务：原子写入、人工复核、依赖失效已测；尚未接入 API/管理界面，也未在任何真实发布中启用。
- 查询规划：车型/年款/动力澄清、多轮代词、跨车不串值；只在规则与 fake runtime 下测试。
- 业务工具：贷款测算与 not_connected 分支完整；未接任何真实门店/库存系统。

## 明确尚未完成

1. **官方语料未审核**：仅有凯美瑞 2027、汉兰达 2026 的 DOM 快照和 RAV4 官方 JSON/CSV 候选，全部 `unapproved`；RAV4 年款仍未明确；PDF 未解析。不可对外宣称官方知识库已上线。
2. **评测集不足**：31 条开发候选，全部未经业务人工复核；240 条与留出集、Recall/MRR/引用支持率的正式测量都未进行。
3. **质量与性能未验收**：没有真实语料下的 p95 延迟、并发、故障矩阵、灰度数据；冒烟结果不能当作性能指标。
4. **多轮与历史链路**：客户端不回传 history 的约束已保持，但 WebSocket 吊销差异、旧意图路径的预算覆盖仍需逐项核查。
5. **管理端真实浏览器流程**：页面与接口契约已测，但未用真实管理员账号在浏览器完成上传/发布/撤回全流程（需要真实登录态）。

## 下一步建议顺序

1. 人工审核三车候选快照并标注年款，补 PDF 解析后再发布首个正式 release。

5. 对接真实业务接口，否则门店优惠与库存继续明确返回未接入。
