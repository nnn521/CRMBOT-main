# CRMBOT 系统技术手册

> 版本：v1.0 | 更新：2026-06-20 | 分支：dev

---

## 1. 系统概述

CRMBOT 是一款基于多 Agent 协作的智能销售辅助系统，技术栈：

| 层级 | 技术 |
|------|------|
| LLM | DeepSeek v4 |
| Agent 框架 | LangGraph（StateGraph + PostgreSQL Checkpointer） |
| 后端 | FastAPI + Uvicorn |
| 向量数据库 | FAISS + Ollama bge-m3 |
| 关系数据库 | PostgreSQL 16 |
| 前端 | React 19 + TypeScript + Vite + Tailwind CSS |
| 状态管理 | Zustand |
| 容器化 | Docker + docker-compose |

## 2. 数据库表结构

### 2.1 业务表

#### sessions（会话表）
聚合聊天会话主表，每个客户对话对应一条记录。

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | UUID | PK，会话唯一标识 |
| `title` | VARCHAR(255) | 会话标题（自动生成或自定义） |
| `status` | VARCHAR(20) | 会话状态：`new` / `active` / `negotiating` / `closed` / `lost` |
| `customer_name` | VARCHAR(128) | 客户名称 |
| `created_at` | DATETIME | 创建时间 |
| `updated_at` | DATETIME | 最后更新时间（排序依据） |
| `handover_mode` | VARCHAR(20) | 接管模式：`ai` / `human` |
| `handover_suggestion` | TEXT | AI 建议回复（人工模式下） |
| `tenant_id` | VARCHAR(64) | 租户 ID（多租户预留，默认 `default`） |

#### conversations（对话记录表）
每条消息的持久化存储。

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | INTEGER | PK，自增 |
| `session_id` | VARCHAR(128) | 所属会话 ID |
| `user_open_id` | VARCHAR(128) | 发送者 openid |
| `role` | VARCHAR(20) | 消息角色：`user` / `assistant` / `system` |
| `content` | TEXT | 消息正文 |
| `intent` | VARCHAR(64) | 意图识别结果（17 种） |
| `metadata_json` | JSON | 附加元数据（sender、agent_name 等） |
| `created_at` | DATETIME | 消息时间 |
| `tenant_id` | VARCHAR(64) | 租户 ID |

#### users（终端用户表）
C端客户用户信息。

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | INTEGER | PK，自增 |
| `open_id` | VARCHAR(128) | 微信小程序 openid（预留） |
| `nickname` | VARCHAR(64) | 用户昵称 |
| `phone` | VARCHAR(20) | 手机号 |
| `avatar_url` | TEXT | 头像 URL |
| `created_at` | DATETIME | 注册时间 |
| `updated_at` | DATETIME | 更新时间 |
| `tenant_id` | VARCHAR(64) | 租户 ID |

#### users_auth（认证表）
登录认证凭据。

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | INTEGER | PK，自增 |
| `username` | VARCHAR(100) | 用户名，唯一 |
| `password_hash` | VARCHAR(200) | bcrypt 哈希密码 |
| `role` | VARCHAR(20) | 角色：`admin`（B端）/ `customer`（C端），默认 `customer` |
| `created_at` | DATETIME | 创建时间 |

#### chat_session_state（会话状态表）
WS 实时状态缓存，与会话一对一。

| 字段 | 类型 | 说明 |
|------|------|------|
| `session_id` | VARCHAR(255) | PK，对应 conversations.session_id |
| `handover_mode` | VARCHAR(10) | 接管模式：`ai` / `human` |
| `high_intent_alerted` | BOOLEAN | 是否已触发高意向提醒 |
| `status` | VARCHAR(20) | 会话状态：`new` / `active` / `closed` |
| `updated_at` | DATETIME | 最后更新时间 |

#### system_configs（系统配置表）
全局配置键值存储。

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | INTEGER | PK，自增 |
| `config_key` | VARCHAR(128) | 配置键 |
| `config_value` | TEXT | 配置值 |
| `description` | TEXT | 配置说明 |
| `is_active` | BOOLEAN | 是否启用 |
| `updated_at` | DATETIME | 更新时间 |
| `tenant_id` | VARCHAR(64) | 租户 ID |

### 2.2 LangGraph 系统表

| 表名 | 用途 |
|------|------|
| `checkpoints` | Agent 工作流断点状态 |
| `checkpoint_blobs` | 断点二进制数据 |
| `checkpoint_writes` | 断点写入记录 |
| `checkpoint_migrations` | 断点迁移版本 |

## 3. API 接口

### 3.1 对话

| 方法 | 端点 | 说明 | 鉴权 |
|------|------|------|:---:|
| POST | `/api/v1/chat` | 核心对话（17 种意图路由） | ✅ |
| GET | `/api/v1/documents/{filename}` | 下载生成的文档 | ❌ |
| GET | `/api/v1/images/{model}` | 获取车型图片 | ❌ |
| GET | `/api/v1/images/` | 列出所有车型 | ❌ |

### 3.2 会话管理

| 方法 | 端点 | 说明 | 鉴权 |
|------|------|------|:---:|
| GET | `/api/v1/chat/sessions` | 获取全部会话列表 | admin |
| POST | `/api/v1/chat/sessions` | 创建新会话 | admin |
| GET | `/api/v1/chat/sessions/{id}/messages` | 获取会话消息历史 | ✅ |
| POST | `/api/v1/chat/sessions/{id}/human-message` | 人工发送消息 | admin |
| POST | `/api/v1/chat/sessions/{id}/handover` | 切换 AI/人工模式 | admin |
| POST | `/api/v1/chat/sessions/{id}/handover/suggest` | 获取 AI 建议回复 | admin |
| POST | `/api/v1/chat/sessions/{id}/handover/dismiss-high-intent` | 关闭高意向提醒 | admin |

### 3.3 报表（v1.0 新增）

| 方法 | 端点 | 说明 | 鉴权 |
|------|------|------|:---:|
| GET | `/api/v1/reports/dashboard` | 仪表盘统计数据 | admin |
| GET | `/api/v1/reports/deals?limit=10` | 近期成交记录 | admin |
| POST | `/api/v1/reports/analyze` | AI 数据分析解读 | admin |

### 3.4 WebSocket

| 端点 | 说明 |
|------|------|
| `/api/v1/ws/{session_id}` | C端客户频道（实时接收人工消息） |
| `/api/v1/ws/session_admin` | B端管理频道（会话更新、新消息提醒） |

WS 事件类型：`new_message`、`session_update`、`handover_update`、`high_intent_alert`

### 3.5 认证

| 方法 | 端点 | 说明 |
|------|------|------|
| POST | `/api/v1/auth/register` | 用户注册 |
| POST | `/api/v1/auth/login` | 登录获取 JWT |

### 3.6 系统

| 方法 | 端点 | 说明 |
|------|------|------|
| GET | `/` | 服务信息 |
| GET | `/health` | 健康检查 |

## 4. Agent 工作流

### 意图路由（17 种）

| 意图 | 常量 | 路由目标 |
|------|------|---------|
| 通用对话 | `general_chat` | → response_node |
| 产品咨询 | `product_inquiry` | → knowledge_node → response_node |
| 报价生成 | `quote_generation` | → document_nodes → response_node |
| 合同生成 | `contract_generation` | → document_nodes → response_node |
| 提案生成 | `proposal_generation` | → document_nodes → response_node |
| 价格谈判 | `negotiation` | → negotiation → response_node |
| 投诉处理 | `complaint` | → complaint → response_node |
| 预约服务 | `appointment` | → response_node |
| 竞品对比 | `competitor_comparison` | → knowledge_node → response_node |
| 配置对比 | `config_comparison` | → knowledge_node → response_node |
| 试驾预约 | `test_drive` | → response_node |
| 金融方案 | `financing` | → response_node |
| 保险咨询 | `insurance` | → response_node |
| 售后咨询 | `after_sales` | → response_node |
| 数据分析 | `data_analysis` | → document_nodes（Excel报表） |
| 库存查询 | `inventory_check` | → response_node |
| 促销活动 | `promotion` | → response_node |

### 工作流节点

```
用户输入 → intent_node（意图识别）
              ├── 产品线 → knowledge_node（RAG检索） → response_node
              ├── 文档线 → document_nodes（参数提取+生成） → response_node
              ├── 谈判线 → negotiation → response_node
              ├── 投诉线 → complaint → response_node
              └── 通用线 → response_node
```

## 6. 知识库

- **格式**：Markdown（`backend/data/knowledge_base/product_catalog_v2.md`）
- **规模**：丰田 26 款车型，133 条结构化数据
- **向量化**：Ollama `bge-m3`（中英文语义检索）
- **检索**：FAISS 向量数据库，Top-K 语义检索

```
    ┌────┴────┐
```

